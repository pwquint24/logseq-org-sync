* org-roam file format --- =.org=
This document describes the subset of Org syntax this sync engine reads
and writes on the org-roam side, and how it compares with the Logseq
=.org= and =.md= formats (see =LOGSEQ-FORMAT.md=).

** Node model
org-roam (v2) treats a file --- or any heading carrying an =:ID:=
property --- as a *node*:

- A *file-level node* is identified by a top-level =:PROPERTIES:= drawer
  containing =:ID:=.
- A *heading-level node* is a heading whose own =:PROPERTIES:= drawer
  contains an =:ID:=.

This engine syncs file-level nodes: one Logseq page ↔ one org-roam file.

** File-level node
#+begin_src org
:PROPERTIES:
:ID:       c7b2a5e4-18c2-4b2a-8c54-1bfa3c678a12
:ROAM_ALIASES: "Alternative Title" "Other"
:END:
,#+title: My Concept
,#+filetags: :topic:emacs:

Freeform text, standard paragraphs, and headings.

,* A heading
#+end_src

- *Identity* --- =:ID: <uuid>= in the top-level drawer.
- *Title* --- =#+title: Page title=.
- *Aliases* --- =:ROAM_ALIASES: "a" "b"= (each alias double-quoted,
  space-separated).
- *Tags* --- =#+filetags: :a:b:= (org colon form).
- *Arbitrary node properties* --- other keys in the top-level
  =:PROPERTIES:= drawer.

** Headings and links
- *Headings* are standard Org headlines; the =*= count is document
  structure, not Logseq block indentation.
- *Heading tags* --- =:tag:= at the end of a headline.  The Logseq
  Markdown =#tag= / =#[[multi-word tag]]= forms map here (see
  =AGENTS.md= §11.3).
- *ID links* --- =[[id:<uuid>][Label]]= are the primary page/heading
  link form.
- *Fuzzy links* --- =[[Label]]= may still appear for unresolved targets;
  the sync leaves them alone unless a node is created.
- *Page links* --- the reconciler maps =[[Title]]= / =[Label]([[Title]])=
  on the Logseq side to =[[id:<uuid>][Title]]= / =[[id:<uuid>][Label]]=
  here, and back (see =AGENTS.md= §3).
- *URL and file links* --- external URLs pass through in org graphs; for
  Markdown graphs the reconciler converts =[Label](https://…)= ↔
  =[[https://…][Label]]=.  File links are syntax-converted and remapped to
  point at the Logseq graph's =assets/= directory (never copied); see
  =AGENTS.md= §3.
- *Block references* --- =((uuid))= and embeds ={{embed ((uuid))}}= are
  preserved verbatim by the parse/write module; the reconciler
  translates them cross-side to =[[id:<uuid>][block text]]= and
  =[[id:<uuid>][#embed block text]]= (see =AGENTS.md= §6).

** Comparison with Logseq =.org= / =.md=
| Concern          | org-roam                                            | Logseq =.org=                                 | Logseq Markdown                                          |
|------------------+-----------------------------------------------------+-----------------------------------------------+----------------------------------------------------------|
| Model            | Document-first: prose, headings                     | Outliner-first: every block is a headline =*= | Outliner-first: every block is an indented list item =-= |
| Page identity    | =:ID:= in top-level drawer                          | =#+id:= in-buffer setting                     | =id:: <uuid>= page property                              |
| Title            | =#+title:=                                          | filename slug; =#+title:= overrides           | filename slug; =title::= overrides                       |
| Aliases          | =:ROAM_ALIASES: "a" "b"=                            | =#+alias: a, b=                               | =alias:: a, b=                                           |
| Page tags        | =#+filetags: :a:b:=                                 | =#+tags: a, b= and/or =#+filetags: :a:b:=     | =tags:: a, b=                                            |
| Block tags       | heading =:tag:=                                    | heading =:tag:=                               | =#tag= / =#[[multi-word tag]]= → =:tags:=                |
| Page links       | =[[id:<uuid>][Title]]=                              | =[[Title]]=                                   | =[[Title]]= / =[Label]([[Title]])=                       |
| Block reference  | heading =:ID:= + =[[id:<uuid>][block text]]=        | =((uuid))= → block's =:id:=                   | =((uuid))= → block's =id::=                              |
| Block embed      | heading =:ID:= + =[[id:<uuid>][#embed block text]]= | ={{embed ((uuid))}}=                          | ={{embed ((uuid))}}=                                     |
| Block properties | heading =:PROPERTIES:= drawer                       | heading =:PROPERTIES:= drawer                 | =key:: value= continuation lines                         |
| Page properties  | top-level =:PROPERTIES:= drawer                     | =#+key: value= settings                       | =key:: value= settings                                   |

** Notes
- org-roam's database (emacsql) and =org-roam-capture-= path are *not*
  used by this engine; the Phase 3 writer (=logseq-org-sync-roam.el=)
  hand-writes the files so the sync stays testable without a live
  org-roam database (=AGENTS.md= §9.11).
- =#+filetags:= is an org-roam-native keyword; the Logseq side uses
  =#+tags:=/=#+filetags:= (=LOGSEQ-FORMAT.md= §7).
